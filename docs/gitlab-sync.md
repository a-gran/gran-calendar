# Синхронизация через GitLab

Синхронизация через GitLab будет добавлена позже.

## Цель

Нужно дать возможность хранить календарь локально и синхронизировать его между
устройствами через GitLab-репозиторий.

## Предварительная идея

Возможный подход:

- хранить базу или экспортированные файлы в Git-репозитории;
- делать commit после локальных изменений;
- отправлять изменения в GitLab;
- при запуске приложения забирать свежие изменения;
- отдельно обрабатывать конфликты.

## Важный нерешенный вопрос

Нужно выбрать формат синхронизации:

- синхронизировать сам SQLite-файл;
- синхронизировать экспорт событий в текстовые файлы;
- синхронизировать JSON-файлы по дням или месяцам.

Пока предпочтительный вариант - сначала сделать стабильное локальное SQLite-хранилище,
а потом добавить экспортный формат для GitLab.
