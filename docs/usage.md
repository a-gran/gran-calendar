# Инструкция по работе с приложением

Этот документ описывает, как пользоваться текущей версией gran-calendar.
Документ будет обновляться по мере развития проекта.
Автотесты проекта описаны в `docs/testing.md`.

## Текущий прототип

Точка запуска приложения находится в `main.py`.

Что уже есть:

- недельный календарь в виде сетки;
- слева показано время с 04:00 до 00:00;
- шаг сетки - 30 минут;
- колонки календаря показывают дни текущей недели;
- текущий день в заголовке недели выделяется желтым цветом;
- событие, которое идет прямо сейчас, выделяется толстой синей рамкой;
- правая панель всегда закреплена справа от календаря;
- протягивание мышью по пустым ячейкам подготавливает создание события в правой панели;
- протягивание мышью по горизонтали создает одинаковые события в выбранные дни после заполнения правой панели;
- протягивание мышью по диагонали создает одинаковый диапазон времени в выбранные дни после заполнения правой панели;
- одиночный клик по пустой ячейке добавляет ее к выделению;
- повторный одинарный клик по выбранной пустой ячейке оставляет ее выбранной для создания;
- можно выделить несколько пустых ячеек кликами;
- двойной клик по событию сразу переводит его в статус `Выполнено`;
- новое событие нельзя создать поверх уже существующего события;
- событие состоит из многострочного названия и заметки;
- название события ограничено 50 символами;
- заметка события ограничена 1000 символами;
- у события есть статус, который выбирается видимыми кнопками в правой панели;
- высота строки времени подстраивается под самое высокое событие в этой строке;
- у события есть уникальный `id`;
- у события есть дата, время начала и время окончания;
- если у события есть заметка, в правом верхнем углу карточки события показывается маркер `N`;
- одинаковые названия событий разрешены;
- одинарный клик по событию выбирает это событие;
- при выборе события правая панель переключается на редактирование;
- при выборе пустой ячейки правая панель переключается на создание события на это время;
- повторный одинарный клик по выделенному событию оставляет его выбранным;
- `Ctrl` + клик по нескольким событиям сохраняет выделение всех этих событий для групповых действий;
- выбор статуса в правой панели сразу применяет его ко всем выделенным событиям;
- событие можно перенести на другой день или время перетаскиванием карточки;
- длительность события можно изменить протягиванием верхней или нижней границы карточки;
- правый клик по событию выбирает его без всплывающего меню;
- событие можно скопировать и вставить в выбранный день и час;
- клавиша `Esc` снимает все выделения;
- клавиша `Delete` удаляет выбранное событие или события в выделенных ячейках;
- клавиша `Ctrl+Z` отменяет последнее изменение события;
- клавиша `Ctrl+Y` повторяет отмененное изменение события;
- клавиша `Ctrl+C` копирует выбранное событие;
- клавиша `Ctrl+X` вырезает выбранное событие;
- клавиша `Ctrl+N` подготавливает создание события в первой выбранной ячейке;
- история отмены хранит последние 10 действий;
- есть кнопки переключения предыдущей, текущей и следующей недели;
- есть кнопка с шестеренкой для визуальных настроек текущей сессии;
- есть переключатель общего календаря по месяцам и годам для выбора конкретного дня;
- есть вкладка года со списком событий выбранного месяца в правой панели;
- события сохраняются в SQLite и остаются после закрытия приложения.
- интерфейс использует темную тему.

## Запуск

```bash
uv venv
source .venv/bin/activate
uv sync
uv run python main.py
```

## Создание события

1. Найдите нужный день недели и время начала.
2. Зажмите левую кнопку мыши на времени начала.
3. Потяните мышь вверх или вниз до времени окончания.
4. Отпустите кнопку мыши.
5. В правой панели введите название события.
6. При необходимости добавьте заметку.
7. Выберите статус события.
8. Нажмите `Create`.

Время начала и окончания берется из выделенного диапазона на сетке.
Если выбранный диапазон пересекается с существующим событием, приложение не создаст новое событие.

## Панель деталей события

Справа от календаря всегда закреплена панель для выбранного события или выбранной пустой ячейки.

Если выбрано событие, в панели можно посмотреть и изменить:

- многострочное название события;
- статус через кнопки без выпадающего списка;
- заметка.

Дата и время показываются только для просмотра: дата сверху, время под ней, крупным жирным текстом.
Панель обновляется после одинарного клика по событию.
Статус применяется сразу после нажатия на кнопку статуса.
Если через `Ctrl` + клик выбрано несколько событий, статус применяется ко всем выбранным событиям.
Чтобы сохранить изменения в названии или заметке, нажмите `Save`.
Сохранение из панели можно отменить через `Ctrl+Z` и повторить через `Ctrl+Y`.
Если выбрана пустая ячейка, в панели показывается время этой ячейки.
Заполните название, статус и заметку, затем нажмите `Create`, чтобы создать событие.
Если ячейка выбрана одним кликом, событие создается на время выбранной ячейки.
Если время выбрано протягиванием мышью, событие создается на весь выбранный диапазон.
Если снять выделение через `Esc`, панель остается на месте и переходит в неактивное состояние.

## Перенос события мышью

Перенос события мышью, или drag-and-drop, нужен для быстрого изменения дня и времени события без открытия окна редактирования.

Как пользоваться:

1. Наведите курсор на середину карточки события.
2. Зажмите левую кнопку мыши.
3. Перетащите карточку на нужный день и время.
4. Отпустите кнопку мыши.

Длительность события сохраняется.
Если новое место пересекается с другим событием, перенос не применяется.
Перенос можно отменить через `Ctrl+Z` и повторить через `Ctrl+Y`.

## Статусы событий

Событие может иметь один из четырех статусов:

- `Важное` - пастельно-красный фон, черный жирный текст;
- `Обычное` - фон как у пустой ячейки, белый жирный текст;
- `Кайрос` - пастельно-желтый фон, черный жирный текст;
- `Выполнено` - пастельно-салатовый фон, черный жирный текст.

Основные тексты внутри приложения используют шрифт без засечек размером 16px.
Время в карточках событий и дата с временем в правой панели показываются размером 20px жирным начертанием.

По умолчанию новое событие создается со статусом `Обычное`.

## Действия без всплывающих окон

Правый клик по событию только выбирает его и показывает данные в правой панели.
Создание и редактирование выполняются через правую панель.
Копирование, вставка и удаление выполняются через горячие клавиши.

## Копирование события в другой день и час

1. Нажмите левой кнопкой мыши по событию, которое нужно скопировать.
2. Нажмите `Ctrl+C`.
3. Нажмите левой кнопкой мыши по времени, куда нужно вставить копию.
4. Нажмите `Ctrl+V`.

При вставке создается новое событие с новым `id`.
Название, заметка и длительность сохраняются.
Статус события тоже сохраняется.
Дата и время начала берутся из выбранного слота сетки.

## Переключение недель

Над календарем находится панель переключения недель:

- `Previous` - показывает неделю раньше;
- `Current` - возвращает календарь к текущей неделе;
- `Next` - показывает неделю позже.
- `Month` - открывает общий календарь по месяцам и годам.
- `Year Calendar` - открывает обзор года с выбором месяца.
- выбор месяца в обзоре года показывает справа список событий этого месяца.
- двойной клик по месяцу в обзоре года открывает этот месяц.
- `Open Month` открывает выбранный месяц в общем календаре.
- выбор дня в общем календаре показывает в правой панели список событий этого дня.
- двойной клик по дню в общем календаре открывает этот день в недельной сетке.
- `Open Day` возвращает недельную сетку и выделяет выбранный день.

## Визуальные настройки

Кнопка с шестеренкой открывает модальное окно визуальных настроек.

Сейчас в нем можно изменить:

- высоту строк календарной сетки;
- ширину правой панели;
- размер времени в карточках событий и правой панели;
- размер заголовка события в карточке;
- размер шкалы времени слева;
- толщину рамки выбранного события;
- размер маркера заметки `N`;
- показ маркера `N` у событий с заметкой.

Интерфейс использует темную тему.
Эти настройки влияют только на внешний вид приложения в текущей сессии.

## Где хранятся данные

События сохраняются в файл:

```text
~/.local/share/gran-calendar/calendar.db
```

Этот файл создается автоматически.
При обновлении установленной программы эта база не должна удаляться или перезаписываться,
поэтому события остаются между запусками.

Если в корне проекта уже есть старый файл `calendar.db`, приложение один раз перенесет его
в пользовательскую директорию при запуске.
