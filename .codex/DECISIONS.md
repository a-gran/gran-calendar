# Принятые решения

- Проект остается desktop-приложением на Python.
- Для графического интерфейса используется PySide6.
- Интерфейс использует темную тему.
- События хранятся локально в SQLite.
- `pyproject.toml` и `uv.lock` являются основным способом управления зависимостями.
- `requirements.txt` не нужен после перехода на uv-проект.
- События могут иметь одинаковые названия.
- Уникальность события определяется через `id`.
- Событие хранит реальные `start_at` и `end_at`, а не строку и колонку таблицы.
- Строка и колонка календаря вычисляются из даты и времени события.
- Корневой `README.md` остается коротким входом в проект.
- Подробная документация ведется в `docs/`.
- Правила работы агентов ведутся в `.agents/`.
- Рабочий контекст Codex ведется в `.codex/`.
- Синхронизация через GitLab будет добавлена позже, после стабилизации локального формата данных.
