# Известные ограничения

На текущем этапе зафиксированы ограничения:

- нет ручного выбора времени начала и окончания в форме деталей события;
- события отображаются в сетке 06:00-22:00 с шагом 30 минут;
- события вне диапазона часов 06:00-22:00 пока не отображаются;
- синхронизация через GitLab не реализована;
- локальный файл `calendar.db` не предназначен для коммита в репозиторий.
