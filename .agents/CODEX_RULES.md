# Правила работы Codex в этом проекте

## Обязательная подготовка перед запросом

Прежде чем выполнять любой запрос пользователя, Codex должен сначала проверить список документов в папках:

- `.agents`;
- `.codex`.

Codex должен обязательно прочитать релевантные документы с правилами из `.agents`.

Документы из `.codex` нужно читать по релевантности задачи: контекст проекта, команды, ограничения, чеклисты или принятые решения.

Если запрос простой и не требует изменений файлов, достаточно использовать уже прочитанные правила и не перечитывать нерелевантные документы.

## Комментарии в коде

Во всех файлах `.py` и `.js` Codex не должен писать комментарии.

Комментарии в коде запрещены, если пользователь отдельно не попросил добавить комментарий.

## Проверка после изменений

После выполнения запроса и применения изменений Codex должен проверить состояние проекта.

Минимальная проверка:

- посмотреть `git status`;
- убедиться, какие файлы были изменены;
- при изменении кода запустить подходящие проверки из `.agents/TESTING_POLICY.md` или явно сказать, почему проверки не запускались.

## Обновление документации

После внесения изменений Codex должен проверить, нужно ли обновить проектную документацию.

Если изменение влияет на функциональность, структуру проекта, проверки, GitLab-синхронизацию, окружение или правила работы, Codex должен обновить только затронутые документы.
