# Стиль работы и оформления

Ответы пользователю давать на русском языке, если пользователь не попросил иначе.

В файлах `.py` и `.js` не писать комментарии.

Комментарии в коде запрещены, если пользователь отдельно не попросил добавить комментарий.

Документацию писать простым русским языком:

- короткие разделы;
- понятные заголовки;
- списки там, где они помогают быстро читать;
- без лишней воды.

Изменения держать небольшими и связанными с запросом.

Интерфейс приложения должен оставаться минималистичным и удобным для календарного планирования.
